# 메트로놈 (개인용 PWA)

윈도우와 휴대폰에서 같이 쓰는 웹앱입니다. 설치 없이 브라우저에서 돌아가고, "앱 설치"를 하면 독립된 앱처럼 실행되며 오프라인에서도 동작합니다.

## 기능
- BPM 30–300 (슬라이더, ±1/±5, 키보드 ↑↓ / Shift+↑↓)
- 박자표 1/4–7/4, 2/2, 3/8–12/8 (6/8·9/8·12/8은 그룹 첫 박도 강박)
- 박 점을 눌러 강박 → 약박 → 무음 전환, 첫 박 강조 켜기/끄기
- 세분: 8분, 셋잇단, 16분, 스윙(50–75% 조절), 점8분, 5·6·7·8잇단 (가로로 넘겨서 선택)
- 박마다 다른 리듬: 박 점을 길게 누르면(PC는 우클릭) 그 박만 세분을 바꾸고, 소리 낼 음만 골라 칠 수 있음
- 박 묶음: 7/8 → 2+2+3 / 3+2+2 등, 고르면 강박 위치가 바뀜
- 폴리리듬: 한 마디에 N번 다른 소리 (예: 3 : 4)
- 테마 7가지 (왼쪽 위 동그라미)
- 소리: 클릭, 우드블록, 비프, 카우벨, 하이햇 (모두 코드로 합성, 파일 없음)
- 탭 템포 (키보드 T), 탭 초기화 버튼 (Esc) — 탭 시작 전 BPM으로 되돌림, 시작/정지 (스페이스바)
- 프리셋 저장/불러오기/삭제 (브라우저에 저장, 기기별로 따로)
- 재생 중 화면 꺼짐 방지

## PC에서 실행
`metronome` 폴더에서:

```
python -m http.server 8765
```

브라우저로 http://localhost:8765 를 열고, 주소창의 "앱 설치" 아이콘을 누르면 윈도우 앱처럼 설치됩니다.
(index.html을 더블클릭해서 열어도 쓸 수 있지만, 그때는 앱 설치와 오프라인 기능이 꺼집니다.)

## 윈도우 exe 설치파일
https://github.com/gustjrwjs/metronome/releases/latest 에서 `Metronome_x.x.x_x64-setup.exe`를 받아 실행하세요.
- 파일이 exe 안에 들어 있어 오프라인에서도 실행됩니다.
- 앱을 켤 때 새 버전이 있으면 업데이트를 물어봅니다(온라인 자동 업데이트).
- main에 올리면 GitHub Actions(`.github/workflows/windows-exe.yml`)가 새 버전(1.0.실행번호)을 자동으로 만들어 Releases에 올립니다.
- 업데이트 서명키는 저장소 Secret `TAURI_SIGNING_PRIVATE_KEY`에 있습니다(공개키는 `src-tauri/tauri.conf.json`). 키를 잃어버리면 설치된 앱이 업데이트를 못 받습니다.
- 처음 설치할 때 "Windows의 PC 보호" 창이 뜨면 '추가 정보 → 실행'.

## 링크 (공유·휴대폰)
https://gustjrwjs.github.io/metronome/ — 이 주소를 열고 위쪽 "📲 앱 설치" 버튼을 누르면 설치됩니다.
버튼이 안 보이면:
- 안드로이드 크롬: 메뉴 → "홈 화면에 추가 / 앱 설치"
- 아이폰 사파리: 공유 → "홈 화면에 추가"

## 고친 뒤 (자동)
- 고치기만 하면 됩니다. 자동 동기화(평일 오후 6시, 로그인 때)가 claude-work에 올리면서 링크(공개 저장소)도 같이 갱신합니다.
- 설치된 앱은 인터넷에 연결돼 있으면 열 때마다 새 파일을 받아옵니다. (오프라인이면 마지막으로 받은 버전으로 동작)
- 바로 반영하고 싶으면 `publish.ps1`을 우클릭 → "PowerShell에서 실행".
